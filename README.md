# بنك سوريا - المحفظة الإلكترونية الشاملة

تطبيق محفظة مالية إلكترونية متكامل مع لوحة إدارة مستقلة.

## الهيكلية التقنية
- **الخادم (Backend):** Node.js / Express المربوط على Render.
- **لوحة الإدارة (Admin Panel):** HTML/JS متواجدة على المسار `/admin`.
- **التطبيق (Mobile App):** Flutter يدعم Android و iOS.

## الميزات الرئيسية
1. **شاشة الإرسال:** دعم خيارات (المفضلة، الإدخال اليدوي، ومسح الباركود عبر الكاميرا).
2. **شاشة الاستقبال:** توليد رمز QR فريد لكل حساب.
3. **تفاصيل المستخدم:** إمكانية رؤية تاريخ الإنشاء، شارة التوثيق الرسمية، وزر إرسال/إضافة للمفضلة.
4. **دعم العملات الأربع:** دولار أمريكي (USD)، ليرة سورية (SYP)، ليرة تركية (TRY)، يورو (EUR) مع تصريف داخلي بأسعار صرف محددة من الإدارة.
5. **صفحة حسابي:** مبوبة بالترتيب الدقيق (تعديل الحساب -> الدعم الفني -> التوثيق -> تجميد الحساب -> رقم الإصدار v1.0.0).
6. **لوحة الإدارة:** إدارة شاملة للأرصدة، الحظر الأمني، إلغاء وعكس التحويلات، مراجعة التوثيق، والتخصيص البصري.
