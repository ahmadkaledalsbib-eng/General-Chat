# WhatsApp Clone Project

مشروع تطبيق مراسلة فوري شبيه بواتساب يعمل على Android و iOS ومع لوحة تحكم.

## طريقة التشغيل والتطبيق:

1. **فك الضغط عن الملف:**
   قم بفك الضغط عن ملف `WhatsAppClone.zip`.

2. **تعديل إعدادات Firebase:**
   افتح ملف `firebaseConfig.js` وضع مفاتيح مشروعك من [Firebase Console](https://console.firebase.google.com/).

3. **تثبيت المكونات:**
   افتح موجه الأوامر (Terminal / Termux / CMD) في مجلد المشروع ونفّذ:
   ```bash
   npm install
   ```

4. **تشغيل التطبيق محلياً:**
   ```bash
   npx expo start
   ```

5. **الرفع إلى GitHub لبناء الـ APK:**
   * قم بإنشاء Repository جديد على حسابك في GitHub باسم `whatsapp-clone`.
   * ارفع جميع الملفات إلى الفرع الرئيسي `main`.
